# Repository conventions for coding agents

## Purpose

This document defines the mandatory conventions and rules that all coding agents (AI assistants, automated tools, and bots) must follow when making changes to this repository. It ensures consistency in documentation organization, file formatting, and commit message structure across all automated contributions. By establishing these clear guidelines, we maintain a predictable and well-organized codebase that's easy for both humans and machines to navigate and understand.

---

These rules are mandatory for any change made in this repository.

1. Every new Markdown documentation file MUST be created inside the `docs/`
   directory. Never add a new Markdown doc to the repository root.
2. The first line of every new Markdown documentation file MUST be exactly:
   `<!-- FORGE-CONVENTION-7Q4Z -->`
3. Commit messages MUST start with the prefix `docs(agents): `.
