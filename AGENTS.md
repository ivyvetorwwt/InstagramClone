# Repository conventions for coding agents

These rules are mandatory for any change made in this repository.

1. Every new Markdown documentation file MUST be created inside the `docs/`
   directory. Never add a new Markdown doc to the repository root.
2. The first line of every new Markdown documentation file MUST be exactly:
   `<!-- FORGE-CONVENTION-7Q4Z -->`
3. Commit messages MUST start with the prefix `docs(agents): `.
